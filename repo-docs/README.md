## 覆盖范围

本指南覆盖纯浏览器工作台外壳、启动能力检查与图形适配器探测、自适应线程调度、对上游 Vitaslop 所加的 Rust 补丁栈、同设备 WebGPU 后处理拦截与切换，以及离线玩家还原和自动化对测编排脚本。Vitaslop 上游完整指令集译码细节、`Vita3K Web` 内部实现源码，以及商业游戏镜像或硬件固件内容，均不在本仓拆解范围之内。

本包采用 Standard 模式：主流程先建立端到端的页面到核心交接模型，专题模块页拆解源码补丁、线程挑选、同设备图像后处理与测试方法，代码地图用于查找修改入口，证据表和术语表提供核对依据。

## 运行与验证入口

以下命令在仓库根运行；本地启动命令仅绑定回环地址，自动对测需另备符合输入指纹的测试文件及硬件 Vulkan 驱动：

```sh
# 1. 运行纯 JS 单元测试（线程策略、图形降级与对测探针）
node --test tests/*.test.mjs

# 2. 离线还原并核对基线静态播放器快照（93 个文件）
python3 scripts/prepare.py players

# 3. 安装对测依赖并启动已构建的修复版 Vitaslop 本地回环服务
npm ci
python3 scripts/serve.py vitaslop --fixed --port 18747

# 4. 在具备 Intel Xe-LPG 驱动的环境下执行工作台集成检查
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/intel_icd.json node tests/workbench.mjs --intel
```

独立文档站仅展示项目介绍、操作指引与源码导览，构建产物不打包模拟器二进制核心、游戏文件、固件或测试运行时归档。
